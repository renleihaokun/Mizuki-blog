### 站点导航  

为了应对奇奇怪怪的网络环境，本站部署了多个镜像线路：

| 线路名称 | 部署平台 | 访问链接 | 特点 |
| :--- | :--- | :--- | :--- |
| **官方主站** | 腾讯云 | [blog.haokun.me](https://blog.haokun.me) | 国内首选，速度最快 |
| **国内备份** | 阿里云 | [esa.blog.haokun.me](https://esa.blog.haokun.me) | 和EO差不多速度 |  
| **海外镜像** | Cloudflare | [cf.blog.haokun.me](https://cf.blog.haokun.me) | 全球加速 |
| **凑数的一** | Vercel | [vercel.blog.haokun.me](https://vercel.blog.haokun.me) | 纯备用 |
| **凑数的二** | Netlify | [netlify.blog.haokun.me](https://netlify.blog.haokun.me) | 备用自己先超限额了 |
| **凑数的三** | Render | [render.blog.haokun.me](https://render.blog.haokun.me) | 你谁 |

### 魔改清单

相对于原始模板，本仓库包含以下深度定制化功能：

- **自动主题：**  自动切换亮色暗色主题。
- **线路切换：**  线路切换组件。  
- **网络检查：**  看看你的网组件。  
- **行旅拾光：**  特色足迹展示页。
