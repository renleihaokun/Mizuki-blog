# 困の小さなブログ  

 > [Mizuki][mizuki] のドキュメントはすでに非常に分かりやすくなっています（「車椅子級」）。このリポジトリをクローンして直接デプロイしないでください。これはテンプレートではありません！！！ **私の個人情報（届出番号、アイコン、ブログ記事、著作権のある実写画像）を保持したまま直接デプロイすることは固く禁じます！**

改善の途上であり、学習の途上でもあります。  
[Mizuki][mizuki] を魔改造し、[Astro][astro] で駆動しています。  
このリポジトリは [Gitee][1] と [GitLab][2] に同名のバックアップがあり、メインリポジトリは [GitHub][3] にあります。

### サイトナビゲーション

### 魔改造リスト

オリジナルのテンプレートと比較して、本リポジトリには以下の高度なカスタマイズ機能が含まれています：

- **自動テーマ：**  ライト/ダークテーマの自動切り替え。
- **ライン切り替え：**  ライン切り替えコンポーネント。  
- **ネットワークチェック：**  「あなたのネットワークをチェック」コンポーネント。  
- **行旅拾光：**  特設フットプリント（足跡）展示ページ。
