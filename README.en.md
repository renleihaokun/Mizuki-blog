### Site Navigation

To handle various network environments, this site is deployed on multiple mirror lines:

| Line Name | Platform | Link | Features |
| :--- | :--- | :--- | :--- |
| **Official Main** | Tencent Cloud | [blog.haokun.me](https://blog.haokun.me) | Best for CN, fastest speed |
| **CN Backup** | Alibaba Cloud | [esa.blog.haokun.me](https://esa.blog.haokun.me) | Same speed as EO |  
| **Overseas Mirror** | Cloudflare | [cf.blog.haokun.me](https://cf.blog.haokun.me) | Global acceleration |
| **Random Backup 1** | Vercel | [vercel.blog.haokun.me](https://vercel.blog.haokun.me) | Purely for backup |

### Customization List

Compared to the original template, this repository includes the following deep customizations:

- **Auto Theme:** Automatic switching between light and dark themes.
- **Line Switching:** Line switching component.  
- **Network Check:** "Check your network" component.  
- **Footprints:** Specialized footprints display page.
