### 计算

* 计算卡方：
  * 自由度>1$$\chi^2 = \sum \frac{(O - E)^2}{E}$$
  * 自由度=1$$\chi^2_c = \sum \frac{(|O - E| - 0.5)^2}{E}$$
* 四分子分析
  * 基因与着丝粒作图(只看单个基因)
    * 先分子囊是MⅠ还是MⅡ(等位基因分离)
    * 基因与着丝粒的重组率： $= \frac{\frac{1}{2}M_{II}}{M_I + M_{II}} \times 100\%$(MⅡ当中只有一半重组了)
  * 基因与基因作图
    * 先分子囊是PD(亲代双型)、NPD(非亲代双型)还是T(四型)
    * 基因与基因重组率 $RF = \frac{\frac{1}{2}T + NPD}{PD + T + NPD} \times 100\%$

### 第 1 章 绪论

- **学科主线**：遗传（保守传递）+ 变异（绝对发展）+ **自然选择** → 物种形成；+ **人工选择** → 品种选育。
- **核心科学史**：

| 时期 | 代表人物与年份 | 核心贡献 |
| :--- | :--- | :--- |
| **孟德尔前** | Lamarck / Darwin / Galton | 获得性遗传 / 泛生论 / 融合遗传（均被否证） |

### 第 2 章 孟德尔遗传

- **豌豆 5 优点**：自花授粉（天然纯系）、性状稳定易辨、繁殖系数高、周期短、易去雄杂交。
- **两大定律**：**分离定律**（等位基因分离入不同配子：F<sub>1</sub> 配子 `1:1`，F<sub>2</sub> 基因型 `1:2:1`、表型 `3:1`）；**自由组合定律**（非同源染色体上非等位基因独立分配，F<sub>2</sub> 为单性状比例乘积）。
- **实现孟德尔比 5 前提**：二倍体且显隐性明确；各类配子均等；生活力与受精机会均等；合子存活率一致；环境一致且大样本。

| 指标 | F<sub>1</sub> 配子 | F<sub>2</sub> 表型 | F<sub>2</sub> 基因型 | F<sub>2</sub> 纯合体 | F<sub>2</sub> 杂合体 | F<sub>2</sub> 组合数 | F<sub>2</sub> 表型比 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **公式** | $2^n$ | $2^n$ | $3^n$ | $2^n$ | $3^n - 2^n$ | $4^n$ | $(3:1)^n$ |

- **$\chi^2$ 适合度检验**：
  $$\chi^2 = \sum \frac{(O-E)^2}{E} \quad (df = \text{分类数} - 1), \qquad df=1\text{ 用 Yates 校正：}\chi^2_c = \sum \frac{(|O-E|-0.5)^2}{E}$$

### 第 3 章 遗传的染色体学说

- **Sutton-Boveri 假说（1903）**：体细胞染色体与基因均成对、配子均成单；减数分裂同源分离与非同源自由组合是孟德尔定律细胞学基础。
- **染色质**：**常染色质**（伸展、浅染、转录活跃）vs **异染色质**（聚缩、深染、转录受抑）。
- **减数分裂关键节点**：

| 时期 / 亚期 | 核心细胞学事件 | 遗传学意义与倍性（**按着丝粒计数**） |
| :--- | :--- | :--- |
| **间期 S 期** | DNA 复制，每条染色体含 2 条姊妹染色单体 | 染色体数仍为 **$2n$** |
| **前期 I 细线/偶线期** | 染色体凝缩；同源染色体**联会**成联会复合体 | 同源配对 |
| **前期 I 粗线期** | 非姊妹染色单体**局部交换** | **连锁交换定律**基础 |
| **前期 I 双线/终变期** | 见 X 形**交叉结**；交叉端化、核膜解体 | 交换显微证据 |
| **中期 I → 后期 I** | 非同源随机排列（*自由组合*）；**同源分离**（*分离定律*） | **就此减半（$2n \to n$）** |
| **后期 II** | 着丝粒分裂、姊妹染色单体分开 | 短暂呈 $2n$，末期 II 成 $n$ 子细胞 |

- **被子植物双受精倍性**：
  - 雄：小孢子母细胞($2n$) $\to$ 小孢子($n$) $\to$ 成熟花粉（1 营养核 $n$ + **2 精核各 $n$**）；
  - 雌：大孢子母细胞($2n$) $\to$ **1 活大孢子**($n$，3 退化) $\xrightarrow{\text{3次有丝}}$ **7 细胞 8 核胚囊**（1 卵 $n$ + 2 助 $n$ + 3 反足 $n$ + **1 中央细胞含 2 极核 $n+n$**）；
  - 双受精：**合子 = $2n$**（精 $n$ + 卵 $n$），**胚乳 = $3n$**（精 $n$ + 两极核 $n+n$）。

### 第 4 章 孟德尔遗传的拓展

- **基因与环境关系 3 组对照**：

| 概念对 | 判别要点与例子 |
| :--- | :--- |
| **外显率 vs 表现度** | **外显率**＝预期表型占该基因型比率（“显不显”）；**表现度**＝已外显个体间深浅程度（“显多少”） |
| **多因一效 vs 一因多效** | **多因一效**＝多基因共控一性状；**一因多效**＝单基因影响多性状（鸡翻毛 `F`、PKU） |
| **温敏突变 vs 拟表型** | **温敏突变**如喜马拉雅兔/暹罗猫 c<sup>h</sup>；**拟表型**＝环境诱导类似表型，性状不遗传但反应能力可遗传 |

- **等位基因互作（5 类）**：**不完全显性**（`1:2:1`，金鱼草）；**共显性**（`1:2:1`，MN 血型、山茶花）；**镶嵌显性**（`1:2:1`，瓢虫鞘翅）；**复等位基因**（同位点 $\ge 3$ 等位：兔毛色 $c^+ > c^{ch} > c^h > c$、ABO 血型、自交不亲和）；**致死基因**（Cuénot 黄鼠 Y<sup>l</sup> 显性毛色、纯合致死，杂交存活 **`2:1`**）。
- **非等位基因互作（双杂合自交 `9:3:3:1` 变型）**：

| 互作类型 | F<sub>2</sub> 表型比 | 基因型归并模式 | 经典例子 |
| :--- | :---: | :--- | :--- |
| **互补作用** | **`9 : 7`** | `9 A_B_ : (3 A_bb + 3 aaB_ + 1 aabb)` | 香豌豆花色、先天性耳聋（`D_E_`） |

| **重叠作用** | **`15 : 1`** | `(9 A_B_ + 3 A_bb + 3 aaB_) : 1 aabb` | 荠菜蒴果（仅双隐性呈卵形） |

### 第 6 章 连锁交换与染色体作图

#### 6-1 真核生物连锁与作图

- **细胞学证明**：粗线期同源染色体**非姊妹染色单体**交换（$RF \le 50\%$）；Creighton-McClintock（玉米 9 号染色体纽结+易位）与 Stern（果蝇 X 缺口+Y 片段）证实物理交换与基因重组同步。
- **两点作图公式（$a,b,c,d$ 依次为 `A_B_`、`A_bb`、`aaB_`、`aabb`）**：

| 测定方法 | 相引组（Cis，`AB/ab`） | 相斥组（Trans，`Ab/aB`） | 说明 |
| :--- | :--- | :--- | :--- |
| **测交法** | $\text{RF} = \frac{b+c}{N}$ | $\text{RF} = \frac{a+d}{N}$ | $a..d$ 为个体数，$N = a+b+c+d$ |
| **F<sub>2</sub> 全群法** | $\text{RF} = 1 - 2r$ | $\text{RF} = 2r$ | $a..d$ 为频率；$r = \frac{1}{2}\sqrt{(a+d)-(b+c)}$（$r+s=0.5$） |
| **F<sub>2</sub> 双隐性法** | $\text{RF} = 1 - 2\sqrt{d}$ | $\text{RF} = 2\sqrt{d}$ | $d = f(aabb)$ 频率，$r = \sqrt{d}$ |

- **三点测验 5 步**：① 后代呈 `2最多:2较多:2较少:2最少` 为 3 连锁（`4多:4少` 为 2 连锁 1 独立）；② 对比亲型（最多）与 `DCO`（最少）唯一互换位点定中间基因；③ 算区间 `RF`（**`SCO` 必须加 `DCO`**）；④ 画图（`1% RF = 1 cM`）；⑤ 算 **$c.c. = \frac{\text{实际 DCO}}{\text{理论 DCO}}$** 与 **$I = 1 - c.c.$**（$c.c.<1$ 正干涉、$=1$ 无、$>1$ 负）。

#### 6-2(上) 真菌四分子分析与影响重组的因素

- **单基因着丝粒作图（顺序四分子）**：$M_I$ 非交换（2 种：`++--`, `--++`），$M_{II}$ 交换（4 种：`+-+-`, `-+-+`, `+--+`, `-++-`）：
  $$\text{RF}(o\text{-}A) = \frac{\frac{1}{2}M_{II}}{M_I + M_{II}} \times 100\%$$
- **双基因作图**（$N = PD + T + NPD$）：**$PD \gg NPD \Rightarrow$ 连锁**，$PD \approx NPD \Rightarrow$ 独立；
  - 直接重组率：$RF = \frac{\frac{1}{2}T + NPD}{N}$；
  - **Perkins 校正图距**：$d = 50 \times \frac{T + 6\,NPD}{N}$（cM）；**Haldane 函数**：$RF = 50\%(1-e^{-m})$，真实图距 $= 50m$。
- **同臂 vs 异臂判别（阶段复习 P49）**：

| 位置 | 距离判别条件 | 子囊分布特征 | 典型例题 |
| :--- | :--- | :--- | :--- |
| **异臂（`A — ● — B`）** | $d(o\text{-}A)$、$d(o\text{-}B)$ **均小于** $\text{RF}(A\text{-}B)$（若两臂和 $> \text{RF}$ 系双交换低估了 $\text{RF}$） | $M_I/M_{II}\text{ T}$ 与 $M_{II}/M_I\text{ T}$ 均多；**$M_{II}/M_{II}\text{ PD}$ 极少** | `thr-arg`（`7.6, 10.0 < 16.7`） |
| **同臂（`● — A — B`）** | 远端基因距着丝粒 **大于** $\text{RF}(A\text{-}B)$ | **$\mathbf{M_{II}/M_{II}\text{ PD}}$ 显著多**（近端交换带整臂入 $M_{II}$）；近端 $M_{II}$/远端 $M_I$ 的 `T` 极少 | `n-a`（`9.30 > 5.20`）、`a-b`（`23.125 > 16.875`） |

- **影响重组 5 因素**：环境温度/射线、性别（**霍尔丹定律**：异配性别少/不交换）、着丝粒异染色质与 **B 染色体**（玉米增、黑麦草降）、倒位/易位抑交换、重组基因。
