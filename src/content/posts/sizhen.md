# Part 1：⭐ 高频考点

## 绪论

### ⭐ 思想道德与法律的关系

思想道德和法律都是调节人们思想行为、协调人际关系、维护社会秩序的重要手段。二者在调节领域、方式、目标上不同，但都是上层建筑的重要组成部分，共同服务于经济基础。

**思想道德 → 法治：** 提供价值准则和正当性基础；促进自觉尊法学法守法用法；更广泛灵活的社会关系调整。

**法治 → 思想道德：** 对思想道德基本原则提供国家强制力保障；通过科学立法将道德融入法律；严格执法公正司法维护公平正义；全民普法守法提高思想道德水平。

> 💡 习近平："法律是成文的道德，道德是内心的法律。法安天下，德润人心。"

### ⭐ 思想道德素质的内涵

思想道德素质是人们的思想观念、政治立场、价值取向、道德情操和行为习惯等方面品质和能力的综合体现，反映着一个人的思想境界和道德风貌，是促进个体健康成长、社会发展进步的重要保障。

### ⭐ 法治素养的内涵

法治素养是指人们学习法律知识、理解法律本质、运用法治思维、依法维护权利与依法履行义务的品质和能力。法律必须转化为人们内心自觉，才能真正为人们所遵行。

## 第一章 领悟人生真谛 把握人生方向

### ⭐ 人生态度的含义与意义

**含义：** 人生态度是指人们通过生活实践形成的对人生问题的一种相对稳定的心理倾向和精神状态。

**意义：** 有什么样的人生观就会有什么样的人生态度。高尚的人生观 → 热爱生活、珍视生命、勇敢战胜困难。乐观向上的人生态度 → 珍惜韶华，实现更大人生价值。

### ⭐ 积极进取的人生态度

1. **人生须认真**：以认真态度对待人生，明确生活目标和肩负的责任
2. **人生当务实**：遵循客观规律，不图虚名，把远大理想寓于具体行动
3. **人生应乐观**：乐观豁达、热爱生活、充满自信，相信前途光明
4. **人生要进取**：开拓进取迎接挑战，不贪图安逸、不因循守旧

### ⭐ 人生价值的实现条件

1. **从社会客观条件出发**：人的创造力依赖社会客观条件，改革开放为实现人生价值提供了有利条件
2. **从个体自身条件出发**：客观认识自己，避免把主观想象当作"真实"存在
3. **不断增强能力和本领**：个人主观努力在很大程度上决定人生价值实现的程度

### ⭐ 正确认识和处理人生矛盾

- **得与失**：不过于看重一时的"得"，不惧怕一时的"失"，跳出个人得失，把小我融入大我
- **苦与乐**：苦与乐对立统一、相互转化，真正的快乐往往由奋斗的艰苦转化而来
- **顺与逆**：顺势而快上，处低谷而力争，处优而不养尊，受挫而不短志
- **生与死**：牢固树立敬畏生命意识，生命价值在于个体付出背后的意义
- **荣与辱**：明确"八个为荣、八个为耻"，荣辱观对思想行为有导向和调节作用

## 第二章 追求远大理想 坚定崇高信念

### ⭐ 理想信念的关系与重要意义

**关系：** 理想和信念总是相互依存。理想是信念所指的对象，信念则是理想实现的保障。**理想信念是人的精神世界的核心，是人精神上的"钙"。**

**重要意义：**
1. **昭示奋斗目标**：理想信念是思想和行为的定向器，使人方向明确、精神振奋
2. **催生前进动力**：崇高坚定的理想信念 → 惊人的毅力和不懈的努力
3. **提供精神支柱**：在遭遇挫折时做到知难而进、迎难而上
4. **提高精神境界**：引导追求更高人生目标，塑造高尚人格

### ⭐ 如何实现理想：理想与现实的辩证关系

- 理想与现实是对立统一的——**对立面**：理想不等于现实，属于"应然"和"实然"的矛盾；**统一面**：理想受现实规定和制约，现实中包含理想的因素
- 两种错误偏向：用理想否定现实 / 用现实否定理想
- 实现理想具有长期性、艰巨性和曲折性
- 艰苦奋斗是实现理想的重要条件
- **实践是联系理想与现实的桥梁**

## 第四章 明确价值要求 践行价值准则

### ⭐ 核心价值观的概念与意义

**概念：** 核心价值观是一定社会形态、社会性质的集中体现，在思想观念体系中处于主导地位，承载着一个民族、一个国家的精神追求。

**意义：**
1. **稳定器**：关系社会和谐稳定、国家长治久安
2. **精神纽带**：凝聚全社会意志和力量
3. **本质是德**：既是个人的德，也是国家的德、社会的德
4. **人心之争**：文化之争本质上是价值观念之争、人心之争

## 第五章 遵守道德规范 锤炼道德品格

### ⭐ 道德的含义

道德是以善恶为评价方式，主要依靠社会舆论、传统习俗和内心信念来发挥作用的行为规范的总和。

### ⭐ 马克思主义道德观：道德的起源和本质

**起源（三个前提）：** 劳动是首要前提；社会关系是客观条件；人的自我意识是主观条件。

**本质（三个方面）：** 反映社会经济关系的特殊意识形态；社会利益关系的特殊调节方式（非强制性）；一种实践精神（知行合一）。

**三大功能：** 认识功能、规范功能、调节功能。

> ⚠️ 道德万能论（片面夸大）、道德无用论（根本否认）都是错误的。

### ⭐ 中华传统美德的基本精神与转化发展

**基本精神：** 重视整体利益；推崇"仁爱"原则；提倡人伦价值；追求精神境界；强调道德修养。

**两种错误思潮：** **复古论**（全盘肯定）、**虚无论**（全盘否定）。正确态度：批判继承、去粗取精、古为今用、推陈出新。

### ⭐ 社会公德：网络生活中的道德要求

1. **正确使用网络工具**：提高信息获取、辨识和应用能力
2. **加强网络文明自律**：文明上网，尊德守法、理性表达，自觉避免沉迷网络
3. **营造良好网络道德环境**：自觉抵制网络欺诈、造谣、诽谤、色情等，反对网络暴力

## 第六章 学习法治思想 提升法治素养

### ⭐ 法律运行（四个环节）

1. **法律制定**：起始性和关键性环节
2. **法律执行**：国家行政机关贯彻实施法律
3. **法律适用**：司法机关处理案件，基本要求是正确、合法、合理、及时
4. **法律遵守**：一切组织和个人依照法律行使权利、履行义务

### ⭐ 建设中国特色社会主义法治体系

**总抓手**：形成五个体系——完备的**法律规范**体系、高效的**法治实施**体系、严密的**法治监督**体系、有力的**法治保障**体系、完善的**党内法规**体系。

**共同推进**：依法治国、依法执政、依法行政。
**一体建设**：法治国家（目标）、法治政府（重点）、法治社会（基础）。

### ⭐ 科学立法、严格执法、公正司法、全民守法

| | 地位 | 核心要点 |
|---|---|---|
| 科学立法 | 前提 | 完善以宪法为核心的法律体系 |
| 严格执法 | 关键 | 法律的生命力在于实施 |
| 公正司法 | 重点 | 公正是法治的生命线 |
| 全民守法 | 基础 | 法律权威源自人民内心拥护和真诚信仰 |

### ⭐ 法治思维的内涵与基本内容

**内涵：** 以**法治价值和法治精神**为导向，运用法律原则、规则、方法思考和处理问题的思维模式。

**基本内容：**
1. **法律至上**
2. **权力制约**
3. **公平正义**
4. **权利保障**
5. **程序正当**

### ⭐ 权利基本内容（人身权利）

人身权利包括：生命健康权、人身自由权、人格尊严权（姓名权、肖像权、名誉权、隐私权等）、住宅安全权、通信自由权。

### ⭐ 提升法治素养的方法

1. **尊重法律权威**：信仰法律、遵守法律、服从法律、维护法律
2. **学习法律知识**：掌握法律法规和法律原理原则知识
3. **养成守法习惯**：增强规则意识，守住法律底线
4. **提高用法能力**：维护自身权利（协商、调解、仲裁、诉讼等），维护社会利益

# Part 2：📖 补充知识点

## 绪论

- **新时代**：三个"意味着"（站起来富起来强起来、科学社会主义生机活力、拓展现代化途径）；两个阶段（2020-2035基本实现现代化、2035-本世纪中叶建成现代化强国）
- **中国梦**：国家的、民族的、也是每一个中国人的
- **时代新人**："立大志、明大德、成大才、担大任"

## 第一章

- **人的本质**：马克思说"一切社会关系的总和"。**社会属性是人的本质属性**
- **个人与社会**：对立统一，最根本的是个人利益与社会利益的关系
- **人生观**：包括人生目的（核心）、人生态度、人生价值，三者相互联系
- **人生目的**：人生观的核心，三个"决定"——决定人生道路、人生态度、人生价值选择
- **人生价值**：包含自我价值和社会价值，社会价值是自我完善的保障
- **马克思主义价值追求**：站在人民立场，以人民为中心
- **三观关系**：世界观决定人生观，价值观对人生观有引导作用
- **错误人生观**：拜金主义、享乐主义、极端个人主义
- **出彩人生**：与历史同向、与祖国同行、与人民同在

## 第二章

- **理想**：特征——超越性、实践性、时代性
- **信念**：特征——执着性、支撑性、多样性。信仰是最高层次的信念
- **信仰马克思主义**：科学的理论、人民的理论、实践的理论、开放的理论
- **中国特色社会主义信念**：只有社会主义才能救中国，只有中国特色社会主义才能发展中国
- **伟大复兴信心**：信仰、信念、信心任何时候都至关重要
- **个人理想与社会理想**：个人理想以社会理想为指引，"得其大者可以兼其小"

## 第三章

- **时代价值**：精神纽带、精神动力、精神支柱
- **爱国主义**：爱祖国大好河山、爱骨肉同胞、爱灿烂文化、爱自己的国家
- **祖国统一和民族团结**：爱国爱党爱社会主义统一、一国两制、铸牢中华民族共同体意识、五个认同
- **反对历史虚无主义**："灭人之国，必先去其史"，树立大历史观和正确党史观
- **总体国家安全观**：以人民安全为宗旨，以政治安全为根本，以经济安全为基础，以军事科技文化社会安全为保障，以促进国际安全为依托
- **改革创新**：改革开放是当代中国最鲜明的特色。做改革创新生力军：树立自觉意识 + 增强能力本领

## 第四章

- **价值观**：反映时代精神、体现民族特色、蕴含阶级立场
- **基本内容**：国家（富强民主文明和谐）、社会（自由平等公正法治）、公民（爱国敬业诚信友善）
- **时代意义**：价值遵循、文化软实力、最大公约数
- **显著特征**：先进性、人民性、真实性
- **普世价值**：西方"普世价值"是资本主义价值观，我们主张全人类共同价值（和平发展公平正义民主自由）
- **积极践行**：扣好人生的扣子——勤学、修德、明辨、笃实

## 第五章

- **道德功能**：认识功能、规范功能、调节功能
- **社会主义道德先进性**：以公有制为基础，以人民服务为核心，以集体主义为原则
- **为人民服务**：先进性与广泛性的统一，从无私奉献到诚实劳动都是为人民服务
- **集体主义**：最高层次（无私奉献）、较高层次（先公后私）、基本要求（顾全大局）
- **中国革命道德**：全心全意为人民服务、始终把革命利益放在首位、修身自律保持节操
- **人类文明优秀成果**：以我为主、为我所用，批判借鉴
- **职业道德**：爱岗敬业、诚实守信、办事公道、热情服务、奉献社会
- **家庭美德**：尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里互助
- **个人品德**：省察克治、慎独自律

## 第六章

- **法律含义**：由国家制定或认可并由国家强制力保证实施的规范体系
- **社会主义法律**：体现党的主张和人民意志的统一，具有科学性和先进性
- **习近平法治思想**：2020年正式提出，"十一个坚持"
- **法治道路**：核心要义是坚持党的领导。五个原则：党的领导、人民主体地位、法律面前人人平等、依法治国与以德治国相结合、从中国实际出发。💡"党大还是法大"是伪命题，"权大还是法大"是真命题
- **法治德治**：如车之两轮、鸟之两翼
- **宪法**：根本大法，最高法律效力。基本原则：党的领导、人民主权、尊重和保障人权、民主集中制、权力监督与制约
- **权利与义务**：如一枚硬币两面，不可分割。某些权利和义务具有复合性（劳动、受教育）
