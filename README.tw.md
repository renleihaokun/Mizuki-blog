### 站點導航  

為了應對奇奇怪怪的網絡環境，本站部署了多個鏡像線路：

| 線路名稱 | 部署平台 | 訪問鏈接 | 特點 |
| :--- | :--- | :--- | :--- |
| **官方主站** | 騰訊雲 | [blog.haokun.me](https://blog.haokun.me) | 國內首選，速度最快 |
| **國內備份** | 阿里云 | [esa.blog.haokun.me](https://esa.blog.haokun.me) | 和EO差不多速度 |  
| **海外鏡像** | Cloudflare | [cf.blog.haokun.me](https://cf.blog.haokun.me) | 全球加速 |
| **湊數的一** | Vercel | [vercel.blog.haokun.me](https://vercel.blog.haokun.me) | 純備用 |
| **湊數的二** | Netlify | [netlify.blog.haokun.me](https://netlify.blog.haokun.me) | 備用自己先超限額了 |
| **湊數的三** | Render | [render.blog.haokun.me](https://render.blog.haokun.me) | 你誰 |

### 魔改清單

相對於原始模板，本倉庫包含以下深度定制化功能：

- **自動主題：**  自動切換亮色暗色主題。
- **線路切換：**  線路切換組件。  
- **網絡檢查：**  看看你的網組件。  
- **行旅拾光：**  特色足跡展示頁。
