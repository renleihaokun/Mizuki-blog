## 13. 出问题时的快速定位

```powershell
# 字体相关（配置错、漏字体、@font-face 没对上）
node scripts/test-font-compression.js

# 类型/模板错误
pnpm astro check

# 构建与产物（含 dist 清理、Pagefind、字体子集化）
pnpm build

# 只清构建产物
pnpm clean

# 本地复现生产行为（搜索/GTM/压缩字体只在这里才有）
pnpm preview --port 4322
```

要看某个改动**之前**的表现，用 `git show <commit>^:<file>` 对比，例如：

```powershell
git log --oneline -12
git show 4d9d8dc^:src/components/organisms/navigation/Search.svelte
```
